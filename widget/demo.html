RGS+ chatwidget

This page stands in for a page of the RGS+ application. The launcher is bottom-right; the panel iframes the agent UI.

Serve it next to a running agent:

docker compose up -d
python3 -m http.server 8000 --directory widget
# http://localhost:8000/demo.html

If the panel opens blank, the agent is refusing to be framed. Set EMBED_FRAME_ANCESTORS in .env to include this page's origin and restart rgsplus-agent.
