# -----------------------------------------------------------------------------
# RGS+ helpdesk — vragen zoals ze binnenkomen.
#
# Blokken worden gescheiden door een regel met alleen `---`. Let op bij het
# plakken van een mail: een handtekening-streepje op een eigen regel splitst
# het blok in tweeën. Haal die weg.
#
# Regels bovenaan een blok die met `#` beginnen zijn metadata:
#   # id:            naam in de transcriptie (uniek)
#   # note:          waar deze vraag op test — gaat mee de transcriptie in
#   # user.<veld>    /  # context.<veld>   → wat de RGS+ applicatie meestuurt
# Al het overige is de vraag zelf, letterlijk zoals de gebruiker hem stelde.
#
# Draaien:  python3 scripts/eval-questions.py evals/helpdesk-nl.txt
#
# De eerste drie zijn echte binnengekomen mails. De rest is daarop gebouwd:
# dezelfde toon en hetzelfde detailniveau (of gebrek daaraan), gespreid over
# de gevallen waarin de agent iets anders hoort te doen dan antwoorden —
# buiten scope, te weinig informatie, kennisbank spreekt zichzelf tegen,
# gebruiker plakt een wachtwoord, gebruiker probeert de instructies te
# overschrijven. Bij elk daarvan is *niet* antwoorden het goede antwoord.
# -----------------------------------------------------------------------------
